Confidentialité

Android2USB copie les fichiers entre les dossiers choisis par l’utilisateur. Les fichiers restent sur son téléphone et son support de destination. L’application ne transmet pas de fichiers au développeur.

L’application ne contient ni publicité, ni analyse d’usage, ni compte utilisateur. Elle n’a pas de permission Internet. La langue, les dossiers autorisés et les informations de reprise sont enregistrés dans son stockage privé local.

Vous pouvez changer la langue et les dossiers dans les paramètres. La désinstallation supprime la configuration locale. Elle ne supprime pas les fichiers source ni les copies sur USB.

Les liens PayPal, GitHub et XS3 ouvrent un navigateur ou une autre application. Ces services appliquent leurs propres politiques. Aucun paiement n’est traité par Android2USB. Le soutien est facultatif et ne donne accès à aucune fonction supplémentaire.

Contact : info@xs3.ch.

Privacy

Android2USB copies files between folders selected by the user. Files stay on the phone and target storage. The app does not send files to the developer.

The app has no ads, analytics or user account. It has no Internet permission. Language, folder access and recovery information are stored in private local app storage.

You can change the language and folders in Settings. Uninstalling removes the local configuration. It does not remove source files or USB copies.

PayPal, GitHub and XS3 links open a browser or another app. These services apply their own privacy policies. Android2USB does not process payments. Support is optional and does not unlock any features.
