# Google Play listing

Name / Nom: Android2USB

## Français
Description courte : Copiez vos fichiers Android vers une clé USB, sans doublons ni publicité.

Choisissez un dossier source et un dossier sur votre clé USB. Android2USB conserve ces paramètres pour les prochaines copies.
Appuyez sur « Copie vers USB » pour copier les fichiers manquants, sous-dossiers inclus.
Suivez la barre de progression et le nombre de fichiers copiés.
Les fichiers déjà présents au même emplacement sont ignorés. Les fichiers source ne sont pas supprimés.
L’application fonctionne localement, sans compte, sans publicité et sans suivi.
Choisissez le français ou l’anglais au premier démarrage. La langue reste modifiable dans les paramètres.
Une clé USB reconnue par Android est nécessaire. Certains appareils demandent un adaptateur USB OTG.
La copie démarre avec le bouton. Elle ne démarre pas automatiquement au branchement.
Le soutien via PayPal est facultatif et ne débloque aucune fonction.

## English
Short description: Copy Android files to USB. Skip existing files. No ads or account.

Choose a source folder and a folder on your USB drive. Android2USB saves these settings for future copies.
Tap “Copy to USB” to copy missing files, including subfolders.
See the progress bar and the number of copied files.
Files already present at the same path are skipped. Source files are not deleted.
The app works locally, with no account, ads or tracking.
Choose English or French at first launch. You can change the language in Settings.
Your Android device must recognize the USB drive. Some devices need a USB OTG adapter.
The copy starts when you tap the button, not when you connect the drive.
Optional support through PayPal does not unlock any features.
